# Verify my-resume

This project requires **Node `^22.22.3 || ^24.15.0 || >=26`** (Angular 22) and pnpm. If the
shell's default Node is older (e.g. 22.17), every command below must be prefixed.

## Environment prefix

Run all `pnpm` / `ng` commands from the repo root with:

```
nvm use 24.20.0 >/dev/null && <command>
```

If pnpm is missing under Node 24, provide it once via corepack:

```
nvm use 24.20.0 >/dev/null && corepack enable && corepack prepare pnpm@11.21.0 --activate
```

(`.nvmrc` pins `24.20.0`; `nvm use` with no arg also works inside the repo.)

## Automated checks — all must pass

Run in order; stop and fix on the first failure.

| Step | Command | Pass criteria |
|---|---|---|
| Lint + format | `pnpm lint` | `All files pass linting.` (Prettier is an error-level rule, so formatting drift fails here — `pnpm lint:fix` autofixes most) |
| Production build | `pnpm build` | `Application bundle generation complete.`, no `ERROR`. Initial bundle is ~505 kB (`maximumWarning` 600 kB, `maximumError` 1 MB in `angular.json`) — a `WARNING` about the budget means it grew; investigate before bumping the budget again |
| Unit tests | `pnpm test` | `Tests <N> passed (<N>)` with **0 failed**. Runner is **Vitest** (jsdom), not Karma. Baseline: 56 tests (41 after the Angular 22 upgrade, +15 with the CV PDF feature) |

`src/build-info.ts` is regenerated by `postinstall` / `prebuild` and is gitignored — never
commit it, and don't be alarmed if a build/test touches its timestamp.

## Manual browser smoke test

Only the résumé (`/home`) ships to users; the rest are labelled learning demos in
`app.routes.ts`. After any change touching routing, forms, i18n, state, or the résumé sections,
start the dev server (`pnpm start`, port **4202**) and check:

- **`/home`** — presentation section renders; scroll down: experience + education timelines
  render with company/school names, logos, and tech-tag chips (these are built with
  `toSignal` + `computed` over Transloco — a blank section means the signal wiring broke).
- **Language switcher** (top-right) — switch `es` / `en` / `zh-CN`: prose + `<html lang>`
  update, and the choice **persists across reload** (`localStorage['lang']`). The "Download CV"
  link's `href` also retargets to `assets/pdf/CV_Jie_Chen_<lang>.pdf`.
- **Dark-mode toggle** — flips and persists (`localStorage['theme']`).
- **`/contact`** — Signal Forms: submit empty → per-field "required" messages; type `Jie` in
  Name → "not allowed"; type `test@example.com` in Email → after ~1 s "already registered"
  (async `validateAsync` + `resource()`); short message → min-length message.
- **`/login`** — submit `admin@example.com` / `admin` → the admin-only paragraphs and the
  `[jcAuth]` / `*jcAuth` template blocks appear; email persists across reload.
- **`/aria-demo`** — click an option in the listbox → "Selected:" updates; the disabled
  "Solid" row can't be selected.
- **`/state-demo`** — click both buttons → after ~1.5 s both the classic-Store panel and the
  SignalStore panel show `title: My portafolio Jie Chen` / `backgroundColor: bg-red-100`;
  `reset()` clears only the SignalStore panel.
- Check the browser console is **clean** (no errors / `NG0…`) on every route visited.

## CV PDF (only when the résumé data or `scripts/cv-template/` changed)

`pnpm generate:cv` re-renders `public/assets/pdf/CV_Jie_Chen_{es,en,zh-CN}.pdf` via headless
Google Chrome (`playwright-core`, no browser download; needs Chrome installed or
`pnpm exec playwright install chromium`). `pnpm build` / `pnpm test` do **not** run it — commit
the refreshed PDFs by hand. Verify each output (needs `poppler` — `brew install poppler`):

- `pdftotext CV_Jie_Chen_en.pdf -` → sections in order Name → Summary → Experience → Skills →
  Education → Languages, every heading before its content, newest role first.
- `pdffonts CV_Jie_Chen_zh-CN.pdf` → every font `emb=yes` / `uni=yes`, **no `Type 3`**.
- `pdfinfo CV_Jie_Chen_zh-CN.pdf` → `Title` + `Author: Jie Chen` set, `Tagged: yes`, `Pages: 1`.

## Deploy sanity (only when deploying)

`pnpm deploy` runs `prebuild`, then `pnpm generate:cv`, then `ng deploy --base-href=/my-resume/`
to GitHub Pages. To check the base-href build locally: `pnpm build && npx http-server
dist/angular/browser -p 4203`.
